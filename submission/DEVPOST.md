# GenHacks 2026 投稿填写指南

官方信息于 2026-11-03 核对。资格为 13 岁及以上的在校学生，全球线上参加，适用 Devpost 的标准地区例外。公司及职业组织不能参赛。可单人或任意人数团队，每人限加入一队，每队一件作品。地区条款适用性、本人学生身份和奖金收款由参赛者按实际情况核实。

- 开发和提交窗口。2026-11-01 00:00 EDT 至 2026-12-26 00:00 EST，对应北京时间 **11 月 1 日 12:00 至 12 月 26 日 13:00**。提交应在截止前完成。
- 原创性。必须在开赛后开始项目，提前开发或抄袭会导致取消资格。可使用开源库、API、模板和 AI 工具，须在项目描述列出实际使用的工具。
- 四个赛道。Healthcare & Environmental，Robotics & IoT，AI, Agentic Systems, Cybersecurity, and Dev Tools，以及 Open。此作品建议 **Healthcare & Environmental**，因为核心是听力困难者和沟通伙伴共同确认康复随访信息。主办方可调整赛道。
- 四项评分。Impact、Technical execution、Creativity、Presentation。公开页未列出权重。演示集中呈现一个实际可理解的场景、一次冲突、一次人工确认和一份可分享的结果。
- 提交物。项目页面含名称、用途、实现和工具。提供可嵌入的 YouTube/Vimeo 实机视频（最长三分钟）、代码链接（用公开 GitHub 仓库）、赛道和全部真实队员。官方公开要求未单列强制部署地址。提交时许可主办方在活动推广中展示项目资料。
- 来源：[赛事主页](https://genhacks-open.devpost.com/) · [规则](https://genhacks-open.devpost.com/rules) · [赛程](https://genhacks-open.devpost.com/details/dates) · [地区例外](https://help.devpost.com/article/144-what-are-the-standard-exceptions-for-global-eligibility) · [Devpost 提交指南](https://help.devpost.com/article/126-know-your-submission-steps)。

## 对照你发的截图

| Devpost 字段 | 填写内容 |
| --- | --- |
| What are your skills? | 个人资料。按实际能力填写，例如 `Python (Basic), HTML/CSS (Basic), Git, GitHub, VS Code, Hearing and Speech Rehabilitation, Research`。 |
| What types of hackathons are you interested in? | 个人兴趣可选 Health、Machine Learning/AI、Social Good、Web、Communication、Beginner Friendly。 |
| Project name | `HearBridge Live` |
| Elevator pitch | `HearBridge Live turns captions into a shared check of dates, times, and rooms, so people can resolve conflicting details before leaving a conversation.` |
| Project Story → About the project | 原样复制 [PROJECT-STORY.md](PROJECT-STORY.md) 的 Markdown 正文，按实际参赛者贡献补写，不删除 AI 披露。 |
| Built with | 逐个添加实际存在的标签。HTML, CSS, JavaScript, Web Speech API, Web Audio API, Node.js。Python 仅用于本地预览。Codex 在 Story 披露。 |
| Try it out | 第一个填实际公开的 GitHub 源码 URL。若自行部署并验证，点 Add another link 加 HTTPS 应用 URL。 |
| Image gallery | 上传应用截图。原截图注明 JPG/PNG/GIF、每张最多 5 MB、建议 3:2、最多 15 张。已附 [房间冲突](media/HearBridge-Live-Conflict.png) 、[中文时间冲突](media/HearBridge-Live-Mandarin.png) 、[双语确认问题](media/HearBridge-Live-Ask.png) 和 [确认后摘要](media/HearBridge-Live-Recap.png) 四张实机截图。 |
| Video demo link | 实际上传后粘贴 YouTube/Vimeo URL。在退出登录的窗口检查能打开、能嵌入，且完整视频不超过 3 分钟。 |
| Save & continue | 保存只代表进入下一步。继续选赛道、填代码链接、核对队员、阅读同意项并完成最终提交。 |

## 提交检查清单

- [ ] 在 GenHacks 报名并确认自己满足资格。选择 Healthcare & Environmental。
- [ ] GitHub 仓库已发布为公开，匿名窗口可看，提交记录使用真实时间，README 可复现。
- [ ] 公开 Story 保留 AI 使用说明，并补充本人实际完成的工作。若继续使用其他工具或资产，更新清单。
- [ ] 逐一跑过 demo、输入、确认、纠正和清除流程。若声称跑过真实语音，亲自录一次并核对浏览器模式。
- [ ] 上传应用实机截图，避免患者或私人信息。
- [ ] 上传并核实可嵌入的 3 分钟以内视频，再填写真实地址。
- [ ] 如选择发布应用，匿名验证 HTTPS 地址后再填。代码和视频链接仍需提交。
- [ ] 所有真实队员加入 Devpost。确认赛道、原创性选项和最终提交状态。
